rclone 1C Backup

rclone 1C Backup is a private utility used to automatically back up 1C database backup files to a personal Google Drive account.

The application is used only by the owner of the Google account and is not offered as a public service.

The application may upload, list, read, and delete backup files in Google Drive for backup rotation purposes.

No Google user data is sold, shared, or transferred to third parties.

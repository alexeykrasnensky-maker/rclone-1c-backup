Privacy Policy

rclone 1C Backup is a private application used by the owner of the associated Google account for automated backup of 1C database files.

Google Drive access

The application accesses Google Drive only to upload, list, read, replace, and delete backup files required for backup storage and rotation.

Data sharing

Google user data is not sold, shared, transferred, or disclosed to third parties.

Data storage

Backup files are stored only in the user's own Google Drive account.

Data retention

Older backup files may be automatically deleted as part of the configured backup rotation policy.

Contact

For questions regarding this application, contact the application owner using the support email shown on the Google OAuth consent screen.
